# Java Quiz App

A simple web-based quiz application built using **Java, HTML, and CSS**. It allows users to answer Java programming questions and view their score with feedback.

## Features

- 5 multiple-choice questions about Java
- Submit answers and calculate the score
- Display score out of 5
- Feedback for unanswered questions
- Try Again option to retake the quiz
- Simple and clean user interface

## Technologies Used

- **Java** — Server and quiz logic
- **HTML** — Quiz structure and form
- **CSS** — Page styling
- **Java Socket Programming** — HTTP request and response handling

## How to Run

1. Install JDK and IntelliJ IDEA.
2. Clone or download this repository.
3. Open the project in IntelliJ IDEA.
4. Run `QuizApp.java`.
5. Open your browser and visit:

   `http://localhost:8080`

6. Answer the questions and click **Submit** to see your result.
